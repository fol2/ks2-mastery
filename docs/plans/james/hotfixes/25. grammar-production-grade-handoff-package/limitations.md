- The uploaded ZIP is a lean review archive. It proves only the included snapshot and intentionally omits many planning/report/evidence files.
- GitHub `main` was used only as exact-file supplemental evidence; this package does not prove the uploaded ZIP is byte-identical to GitHub `main`.
- The patch was produced against the uploaded ZIP snapshot, not against a live Git worktree.
- Production was not fully verified. The landing page was reachable, but `/demo` timed out in the browser fetch layer, and no live Grammar user journey was completed.
- No Code Reviewer and Contract Auditor loop was run to the exact final-agent PASS requirement. That loop is required in the contract after local implementation.
- The active/passive explanation family still uses arrows intentionally to show an active-to-passive transformation. It should be explicitly reviewed by the local agent, but it is not patched here because it appears to be the worked material for an explanation task, not a hidden answer leak in a fix task.
