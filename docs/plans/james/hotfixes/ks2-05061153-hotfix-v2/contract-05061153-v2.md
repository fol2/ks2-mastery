# Reading Injected-Clock Scheduler Hotfix Contract

## Goal

Make Reading due/review scheduling and analytics deterministic under the server/Worker command clock.

## Required implementation

1. `nodeStatus(node, nowValue)` must use the supplied timestamp.
2. `questionWeakness(data, question, nowValue)` must use the supplied timestamp.
3. Reading passage/question selection must pass the command timestamp into weakness scoring.
4. `buildStats(data, nowValue)` must use the supplied timestamp for skill status and retry due counts.
5. `buildAnalytics(data, nowValue)` must use the supplied timestamp for `generatedAt`, skill rows, and review queue.
6. `createServerReadingEngine.apply()` must pass the computed command timestamp `t` into `buildStats()` and `buildAnalytics()`.
7. A regression test must prove that `dueAt: 1500` is not due when injected `now()` returns `1000`.

## Acceptance commands

Run from repo root:

```bash
git apply reading-clock-hotfix-v2.patch
node --check worker/src/subjects/reading/engine.js
node --check tests/worker-reading-runtime.test.js
node --test tests/worker-reading-runtime.test.js tests/reading-content-contract.test.js tests/reading-subject-registry.test.js
```

Expected focused result:

```text
16 pass / 0 fail
```

## Rollout boundary

This is a narrow Reading runtime determinism fix. It should not change Punctuation QG, Grammar QG, rewards, Hero coins, monsters, or production smoke artefacts.
