Bug:

Reading scheduling/read-model helpers still used wall-clock `Date.now()` in paths that should be deterministic under the injected Worker command clock.

Risk:

A future-dated skill or retry queue item can appear due during replay/tests/Hero-launched Reading sessions because the engine compares `dueAt` to the real current time instead of the injected command timestamp.

Patch effect:

- Threads `nowValue` through `nodeStatus()`, `questionWeakness()`, passage/question choice, `buildStats()`, and `buildAnalytics()`.
- Makes `analytics.generatedAt`, `stats.overview.due`, and `analytics.reviewQueue` respect the injected engine clock.
- Adds a regression test: `reading due stats and review queue use the injected command clock`.
