## New P17 family types

The delta adds these new family styles across concepts:

- `precision_choice` — a clean answer selection with fresh learner-visible surfaces.
- `misconception_repair` — a learner has chosen or written a plausible wrong answer; the child fixes it.
- `written_reason` — one-sentence explanation to avoid shallow recognition.
- `table_classify` — compact row classification for repeated retrieval in a varied format.
- `transfer_apply` — solve the original item, then apply the same rule to a new sentence/phrase.
- `examiner_trap_contrast` — extra trap-family for priority concepts, contrasting a defensible answer with a tempting near miss.
